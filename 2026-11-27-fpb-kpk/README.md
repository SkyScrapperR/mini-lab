# FPB dan KPK

Menghitung FPB dan KPK dua bilangan atau lebih beserta faktorisasi primanya, cocok untuk belajar matematika SD.

## Cara menjalankan
```
python fpb_kpk.py 12 18
python fpb_kpk.py 24 36 60
```

## Contoh keluaran
```
12 = 2^2 x 3
18 = 2 x 3^2
FPB = 6 (pangkat terkecil dari faktor yang sama)
KPK = 36 (pangkat terbesar dari semua faktor)
```
