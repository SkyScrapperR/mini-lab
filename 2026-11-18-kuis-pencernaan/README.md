# Kuis Sistem Pencernaan

Kuis pilihan ganda interaktif tentang sistem pencernaan manusia (10 soal, urutan soal dan pilihan diacak). Setelah menjawab, muncul penjelasan singkat dan skor akhir.

## Cara menjalankan
Buka `index.html` di peramban mana pun. Tidak perlu server atau instalasi.

## Contoh keluaran
```
Soal 1 dari 10
Pencernaan kimiawi karbohidrat dimulai di ...
 > Mulut  -> "Benar! Enzim amilase pada air liur mulai memecah amilum ..."
...
Hasil: 8/10 (80) - Hebat! Pemahamanmu sangat baik.
```
