# Simulasi Dadu

Mensimulasikan pelemparan 1–4 dadu dan membandingkan peluang empiris (hasil percobaan) dengan peluang teori. Cocok untuk belajar peluang di SD/PGSD.

## Cara menjalankan

```
python3 simulasi_dadu.py                  # 1 dadu, 600 lemparan
python3 simulasi_dadu.py -n 6000 -d 2 --seed 42
```

Opsi: `-n` jumlah lemparan, `-d` jumlah dadu (1–4), `--seed` agar hasil bisa diulang. Tidak butuh pustaka tambahan.
