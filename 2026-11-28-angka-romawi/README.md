# Konverter Angka Romawi

Mengubah bilangan biasa (1-3999) menjadi angka Romawi dan sebaliknya. Penulisan yang tidak baku (misalnya `IIII` atau `VX`) ditolak, cocok untuk belajar di SD.

## Cara menjalankan

```
python3 romawi.py 2026 MCMXCIV 14 IIII
python3 romawi.py            # mode interaktif
python3 romawi.py --uji      # jalankan uji otomatis
```

## Contoh keluaran

```
2026 = MMXXVI
MCMXCIV = 1994
14 = XIV
IIII: 'IIII' bukan penulisan angka Romawi yang baku
```
