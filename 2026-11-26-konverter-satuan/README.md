# Konverter Satuan

Alat baris perintah untuk mengubah satuan panjang (km–mm), berat (ton–mg), dan waktu (hari–detik). Cocok untuk latihan matematika SD.

## Cara menjalankan

```
python3 konverter.py 2.5 km m
python3 konverter.py 90 menit jam
python3 konverter.py --tangga berat
```

## Contoh keluaran

```
2.5 km = 2500 m
90 menit = 1.5 jam
ton > kuintal > kg > hg > dag > g > mg
```

Mengubah antar besaran berbeda (misal `km` ke `kg`) menampilkan pesan galat.
