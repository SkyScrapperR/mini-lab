# Teks ke Infografis (SVG)

Mengubah teks ringkas menjadi infografis bergaya alur bernomor dalam format SVG. Cocok untuk bahan ajar atau catatan belajar.

## Cara menjalankan

```
python3 teks_ke_infografis.py [berkas_masuk] [berkas_keluar]
python3 teks_ke_infografis.py contoh.txt infografis.svg
```

Format masukan: baris pertama adalah judul, baris berikutnya `Judul poin: penjelasan`.

## Contoh keluaran

```
Infografis 'Siklus Air' dengan 4 poin disimpan ke infografis.svg
```

Hasilnya ada di `infografis.svg` (buka di peramban). Tanpa pustaka tambahan.
