# Kalkulator Bangun Datar

Alat kecil untuk menghitung keliling dan luas 8 bangun datar: persegi, persegi panjang, segitiga (rumus Heron), lingkaran, trapesium, jajar genjang, belah ketupat, dan layang-layang. Berguna sebagai bahan belajar matematika SD.

## Cara menjalankan

```
python3 bangun_datar.py                      # mode interaktif
python3 bangun_datar.py persegi_panjang 8 3  # mode argumen
```

Urutan ukuran tiap bangun ada di docstring `bangun_datar.py`.

## Contoh keluaran

```
Bangun : segitiga
Ukuran : 3.0, 4.0, 5.0
Keliling = 12.00
Luas     = 6.00
```
